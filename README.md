# Morrow

**A Mobile App for Personal and Shared Expense Management**

Morrow is a mobile application project designed to help individuals, couples, and groups manage their finances in one place.

The goal is to create a simple and intuitive experience for tracking personal and shared finances, with future support for multiple currencies, budgets, and savings goals.

> **Project Status: In Development**

## Overview

Morrow is being developed as a mobile-first application with a focus on simple navigation, user authentication, and flexible financial spaces.

Users will eventually be able to create personal or shared spaces to organize their financial activities.

## Current Features

- User registration with Supabase Authentication
- User login and session management
- Password recovery screen
- Authentication navigation flow
- Personal and shared space setup screens

*Features are listed according to their current implementation status. Some screens are still under development.*

## Design

Morrow uses a minimal visual style with warm ivory backgrounds, deep green elements, and soft sage accents.

The design focuses on readability, simplicity, and a comfortable user experience.

## Planned Features

The following features are planned for future development:

- Personal and shared expense tracking
- Group invitations and member management
- Multi-currency expense management
- Exchange rate integration
- Weekly and monthly budgets
- Personal savings goals
- Spending summaries and category analysis

## Development Goals

The project is being developed incrementally, starting with authentication and application setup before moving on to core financial management features.

Future development will focus on backend integration, data management, and a reliable user experience.
